## 확정되지 않아 추가하지 않은 것

- 미스릴/오우거 가죽의 상위 제작법. 운석→운석강→문스톤 경로와 생명의 나무 STA100 회복은 기존 확정 데이터대로 동작합니다.
- 나머지10명은 TXT 설계 초안. 둔기/활/투척/권법, 함정, 해킹, 특별 보스, 가드/부상/무기 파괴, 공개 매칭/봇/랭크/영구 전적은 미구현.

## 실행 환경

Sites Worker·D1에 온라인 방 대전을 연결했습니다. 사용자는 링크 공개를 승인했습니다. 서버 교체 후 DB에서 복구하며 세션 발급 후2시간, 전투 연결 종료 유예60초입니다. 대기 방 무활동3분/진행 방2시간/종료 방1시간 후 만료됩니다. 영구 전적은 아닙니다.

## 조우 정보 표시 갱신

현재 조우한 서번트의 장착 장비 6칸·레벨·사용 숙련도 등급은 공개합니다. 상대 가방·정확한 HP/STA·숙련도 점수·보구 대기시간은 공개하지 않습니다. 중앙 전신 이미지 영역은 비워 두고 실제 피해량·피격·빗나감·영시 회피를 서버 피드백으로 표시합니다. 전투 규칙과 조우 유지 시간은 변경하지 않았습니다.

## 공통 전투 기반 확장

보통/공격/은신 태세와 공통 상태 10종, 제어 면역을 서버/혼자 연습에 연결했습니다. 새 캐릭터가 이 처리를 재사용할 수 있습니다. 현재 캐릭터2종의 스탯과 보구 수치는 유지합니다. 가드는 미채택입니다. 상태 아이콘은 본인 카드 오른쪽, 전장 기록 위에 배치합니다. 현재 공통 상태는 서번트 대상이며 동물 상태 부여는 포함하지 않습니다. 클라이언트 상태 부여 API는 없고, 연습의 명시적 테스트에서 각 효과를 확인할 수 있습니다.



## 라이더 검증

신규23개와 기존72개, 총95개 검증을 통과했습니다. 브라우저에서4종 선택, 판넬 사격과 횟수, T재장전6/6·예비19, 링크 직접 제작+4→+5 및 검격62피해를 확인했습니다. 모바일390px에서 가로 넘침이 없고 새 정보 영역이 화면 안에 배치됨을 확인했습니다. 콘솔 오류 없음. 실제 참가자 다인 밸런스는 미검증입니다.

## v0.14 온라인 저장과 동시 접속

D1에 방 상태와 요청 처리 기록을 저장하고 revision 비교로 동시 변경을 조정합니다. 참가 세션과 정원도 같은 트랜잭션에서 확정합니다. Worker 복원 후 지속 효과와 예약 행동은 원래 시각으로 따라잡습니다. 세션 키는 해시로 저장합니다. 재전송은 같은 요청 ID를 유지하고 클라이언트는 과거 revision을 무시합니다. 초대 링크에는 방 코드만 담습니다.

검증: 112개 테스트, 실제 로컬 Worker 4클라이언트 전투 시작, 브라우저 2탭 피해·재접속·새로고침 후 HP 보존. 대규모 부하·장기간 실전 밸런스는 별도입니다.
