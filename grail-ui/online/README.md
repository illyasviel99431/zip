# 성배전쟁 온라인 알파 v0.14.0

같은 사이트에서 방 코드 또는 초대 링크로 최대 4명이 대전합니다. 2~3인 검증 시작도 허용합니다. 알트리아·유키나·아무로·링크를 선택할 수 있습니다. 방문자는 Node 설치나 로컬 서버 실행이 필요 없습니다.

방 만들기 → 초대 링크 복사 또는 6자리 코드 공유 → 참가 → 각자 준비 완료 → 방장 시작 → 각자 시작 지역 확정 → 전원 확정 후 전투 시작.

## 온라인 서버

Cloudflare Worker와 D1에 방·세션·전투 상태를 저장합니다. 기존 URL을 사용하며 사용자는 링크로 누구나 접속 가능하게 공개하도록 요청했습니다.

서버가 위치·HP/STA·지역 공통 재고·탐색·제작·탄약·쿨타임·피해·탈락·승패를 판정합니다. 동시 변경은 방 revision을 비교해 원자적으로 저장합니다. 같은 행동 재전송은 한 번만 소비하며 늦게 도착한 응답은 최신 화면을 덮어쓰지 않습니다.

새로고침은 같은 탭의 세션으로 복귀합니다. 전투 연결 종료 유예는 60초, 세션은 발급 후 2시간 유효합니다. 대기 방은 무활동 3분, 진행 방은 2시간, 종료 방은 1시간 후 만료됩니다. Worker 교체 후에도 만료 전 방을 D1에서 복구합니다. 영구 계정·전적·공개 자동 매칭·봇·랭크는 제공하지 않습니다.

초대 링크에는 방 코드만 담습니다. 세션 키는 URL에 넣지 않고 DB에는 해시만 저장합니다. 상대 위치 목록·가방·정확한 HP/STA·보구 CD는 숨깁니다. 조우한 상대의 장비와 HP 비율은 기존대로 표시합니다.

## 소스와 실행

- public/: 게임 UI·공통 엔진·214아이템·57제작법·모든 기존 이미지.
- server/online-service.mjs: 온라인 API·방 저장·동시 변경·세션 인증.
- app/api/[action]/route.ts: Worker API. app/route.ts: 게임 화면.
- db/schema.ts, drizzle/: D1 스키마와 배포 마이그레이션.
- game-server.mjs, serve.mjs: 이전 메모리 방식 로컬 서버의 호환용 소스.

GitHub에서 받은 소스에는 사이트별 `.openai/hosting.json`이 없습니다. 먼저 `.openai` 폴더를 만들고 `hosting.example.json`을 `.openai/hosting.json`으로 복사하세요. 예제는 로컬 D1 바인딩만 설정합니다. 실제 배포에는 본인의 사이트 ID와 설정을 별도로 사용합니다.

Node 22.13 이상에서 npm ci → npm run build → 새 로컬 DB에 아래 마이그레이션 적용 → npm start 순서로 개발 서버를 실행합니다. 같은 DB에 초기 마이그레이션을 반복하지 마세요.

    node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_complete_famine.sql

혼자 연습과 서버 대전은 같은 game-core.js 규칙을 사용합니다. 캐릭터 그림은 추가하지 않았습니다.

## v0.5 시작 지역과 지도 변경 (2026-11-03)

실제 방 대전과 혼자 UI 연습 모두 지도에서 첫 지역을 고릅니다. 서버 방은 전원 확정 전까지 경기 시간을 시작하지 않으며 시작 배치에 STA/CD가 들지 않습니다. 지도는 8개 지역 경계·지형·현재 위치·목적지·폐쇄/예정·목표 재료 발견 지역을 구분합니다. 지역 선택만으로 이동하지 않으며 상세에서 이동/령주 도주를 확정합니다. 지도 도형은 이동 인접 제한이 아닙니다.
공통 규칙 TXT는 사용자 요청에 따라 기존 파일 안에서 v0.4로 개정했습니다.

## v0.6 지도·빠른 버리기·시각 개선 (2026-11-03)

선택 지역 외곽선을 모든 지역 위에 별도 경로로 그려 인접 지역에 가려지지 않게 수정했습니다. 현재 위치 테두리도 위에 표시하며 선택 표시가 최상단입니다.
가방 아이템 위에 커서를 두고 V를 누르면 1개를 버립니다. 매 키 입력 때 현재 커서 아래 요소를 다시 확인하므로 서버가 가방 DOM을 갱신해도 이전 슬롯 요소를 재사용하지 않습니다. 키를 길게 눌러 반복해서 버리기, 입력창 입력 중, 로비·탈락·결과·모달 중의 새 호버 단축키는 차단합니다. 기존 아이템 상세창의 V 버리기는 유지합니다. 바닥 아이템 M에서 회수할 수 있습니다.
8개 지역별 자체 SVG 배경을 추가했습니다: 주택가 거리·학교 건물·공장 설비·성당·숲길·연못과 정자·항구 크레인·호텔. 캐릭터 이미지는 추가하지 않았습니다. 배경은 지역 이동 때 함께 바뀝니다.
검정/금색 중심 테마를 밝은 청회색 패널로 바꾸고, 탐색 녹색·이동 파랑·휴식 청록·공격 주황·보구 보라·령주 붉은색으로 구분했습니다. 지도 선택의 금색 표시는 버튼 색과 별개로 유지합니다. 글자 대비와 행동/아이템 안내 크기를 높였습니다.
브라우저에서 공장 전체 선택 테두리, 공장·연못 배경, 커서 아래 V키로 빵 2개→1개, M 창에 빵1개가 남는 동작을 확인했습니다.

## v0.7 원작22개 지역과 배치 (2026-11-03)

21개 일반 지역과 기본 폐쇄 연구소를 지도/배치 선택/이동/탐색에 연결했습니다. 연구소는 고정 아이템0종이며 해킹 미구현으로 진입 불가입니다. 인원 정원은4인으로 유지합니다.

2022년 공개 보존 자료의 지역 상세 행 기준 고정154종·초기1278발견 묶음, 총212아이템을 제공합니다. 물/총알 등은 발견 묶음과 실제 단위 재고를 구분합니다. 기존53개 제작법은 유지하며 모든 신규 아이템의 상위 제작법은 아직 추가하지 않았습니다. 베기/찌르기 외 신규 무기, 함정/해킹/재장전은 전투 준비 중으로 표시합니다. 기존 동물4종의 수치/드롭은 프로젝트 기준입니다.

무작위 배치는 시작 시 물15/화살6/총알6/반창고10묶음,180초에 생명의 나무5/운석6/미스릴6/오우거 가죽2개입니다. 현재 열린 일반 지역에 배치하며 한번만 실행합니다. 도감에는 고정 지역과 무작위 시간을 구분하고 실제 무작위 위치/재고는 전송하지 않습니다. 원작 서버 원본이 아닌 공개 표 기준이며 충돌은 설계서 정리/원작 데이터/지역_22개_아이템_배치.json에 기록했습니다.

금지구역은 기존 경기 길이를 유지하면서21→15→9→4→1로 축소합니다. 지도는 자체 SVG 경계이며 원작 지형 그림을 복제한 것은 아닙니다. 22개 구역의 선택 테두리는 마지막 레이어에 표시하고 작은 화면에는 지역 목록 선택을 추가했습니다. 새 지역14곳의 벡터 배경도 추가했습니다.

검증: node --test game-server.test.mjs world-rules.test.mjs. 원작22지역 모든 배치 행·묶음 환산·21지역 이동/연구소 차단·무작위 등장/중복 방지/폐쇄지역 제외·최종1지역·공유 재고 차감·지도 면적 누락 검증을 포함합니다.

## v0.7.1 섬 지도 시각화 수정 (2026-11-03)

원작 루미아 지도(https://gamerch.com/blacksurvival/460820 및 해당 지도 이미지)를 직접 확인해 지역의 상대적 위치를 다시 배치했습니다. 항구/공장/슬럼은 북서쪽, 호텔/성당은 동쪽, 연구소는 중앙, 병원/숲은 남서쪽, 모래사장은 남쪽, 절/등대는 남동쪽입니다. 지형과 건물은 직접 작성한 SVG이며 원작 이미지 파일을 배포하지 않습니다.

균등 분할을 없애고 굴곡 있는 해안·도로·숲·산·물과22개 랜드마크로 표현합니다. 지역 경계는 수동으로 지정했고 선택/현재/폐쇄 상태만 강조합니다. 이름 표지판과 건물도 클릭할 수 있으며, 현재 위치/선택 경계는 건물 뒤에서 표시해 건물 그림을 가르지 않습니다. 기본 아이콘용 SVG 선 스타일이 지도 전체에 적용되지 않게 분리했습니다.

22지역, 아이템 배치/수량, 정원, 이동/폐쇄 규칙은 v0.7을 유지합니다. 지도 클릭 영역끼리 겹치지 않는지, 표지판 중심이 해당 구역에 들어가는지 검사합니다. 브라우저에서21개 일반 지역 표지판의 선택 결과/테두리, 건물 클릭, 키보드 선택을 확인했습니다.
