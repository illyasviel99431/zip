# 성배전쟁 UI 프로토타입 v0.3

캐릭터 이미지를 사용하지 않은 브라우저 단독 UI입니다. 외부 게임 서버, 계정, 저장 기능은 연결되어 있지 않습니다.

`dist/index.html`을 열거나 이 폴더에서 `node serve.mjs`를 실행하면 사용할 수 있습니다.

- 탐색/조우 화면을 분리하고 현재 상황의 행동만 표시. 조우 만료 3초 후 탐색 UI로 복귀
- 가방 6칸, 장착품 6칸, HP/STA 빠른 회복
- 전체 102개 아이템 이름 부분 검색, 53개 제작법, 상위/하위 재료 이동, 발견 지역, 목표 설정, 이전 아이템
- E키 이동 지도 전용 창. 지역을 선택하기 전에는 자원을 소비하거나 이동하지 않음
- 내 장비, 능력 설명, 아이템 도감, 바닥 아이템, 휴식, 령주를 각각 별도 창에서 조작
- 내려놓은 아이템은 같은 지역의 바닥 아이템 창에서 0.5초에 회수
- 상황 테스트에서 조우, 동물, 피격, 폐쇄 예고, 초기화 확인
- 내 상태창, 상대 서번트 조우, 서번트 선택창의 이미지 영역. 실제 그림은 아직 비워 둠

이미지 연결은 `dist/character-art.js`의 캐릭터별 `src`에 로컬 파일 경로를 지정합니다. 예: `assets/characters/artoria.webp`. 현재 값은 `null`이므로 그림을 요청하지 않고 빈 틀을 표시합니다. 같은 원본을 세 화면에서 재사용하며 `object-fit: contain`으로 표시하고, 이름·HP·STA·행동 버튼은 이미지 바깥에 둡니다. 이미지 레이어는 클릭을 가로채지 않으며, 불러오기 실패 시 빈 틀로 돌아갑니다. 실제 일러스트가 제공된 뒤에는 그림의 여백·무기 끝·얼굴 크기를 별도로 확인해야 합니다.

화면 확인을 위해 탐색 결과는 아이템→서번트→아이템→동물→아이템 순서로 반복됩니다. 실제 확률 시스템을 구현한 것은 아닙니다. 테스트용 철광석과 고철을 한 개씩 지급합니다. 초기 캐릭터 수치와 시작 장비·음식은 내부 설계서를 사용합니다.

이 프로토타입은 전투 밸런스 검증용 구현이 아닙니다. 숙련도 성장/전체 장비 효과/상대의 자율 행동/시체 회수/실제 멀티플레이 확률 판정은 후속 구현 범위입니다. 마력 간섭은 테스트에서 확인할 수 있도록 확정 적용하며, 실제 대마력의 상태 이상 확률 감소 판정은 후속 전투 엔진에 연결해야 합니다. 바닥 아이템 창은 현재 체험에서 직접 내려놓은 물품만 표시합니다. 생존자 목록 역시 실제 접속자 목록이 아닌 UI 예시입니다.

단축키: 탐색 R, 지도 열기/닫기 E, 평상시 휴식/조우 시 도주 S, 일반 공격 A, 조우 보구 Q, 평상시 알트리아 지역 보구 A, 내 장비 C, 도감 F, 바닥 아이템 M, 령주 X, 회복 1/2, 생존자 예시 Tab, 닫기/행동 취소 Esc. 아이템 상세창에서 R 사용/장착, F 제작 가이드, V 버리기. 제작 가이드에서 Space 제작. 검색창에 입력 중에는 행동 단축키를 실행하지 않습니다.

검색은 제작 가능 여부·재료 이름으로 결과를 섞지 않고 아이템 이름의 포함 문자열로 동작합니다. 검색어 입력 시 분류 필터를 전체로 복귀하며, 이후 직접 분류를 선택할 수 있습니다. 입력창은 결과 갱신 시 교체하지 않고 한글 조합 종료도 처리합니다.

원작 자료: 사용자 제공 제작창, [PC 조작 안내](https://gamerch.com/blacksurvival/461665), [아이템 가이드 설명과 보존 화면](https://kaiten-ice.hatenablog.com/entry/2020/02/28/211753). 원작의 종료된 클라이언트를 실행한 검증은 아닙니다. 우리 게임에 없는 태세·부상 치료·상점은 추가하지 않았습니다. 가이드의 지역 버튼은 이동 지도를 열며, 이동은 지도의 목적지 선택 시에만 수행합니다.

데이터 원본: `../설계서 정리/게임_아이템_데이터.json`. UI에 포함된 `dist/data.js`는 이 파일에서 생성한 정적 스냅샷입니다.
