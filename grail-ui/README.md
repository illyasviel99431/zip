# 성배전쟁 플레이 알파 v0.13.0

## 실행

프로젝트의 grail-ui 폴더에서 게임_서버_실행.cmd를 더블 클릭하거나, Node.js로 node serve.mjs를 실행한 뒤 http://127.0.0.1:4173 을 엽니다. 외부 패키지 설치는 필요 없습니다. 같은 컴퓨터의 서로 다른 브라우저 탭에서 방 생성·참가를 시험할 수 있습니다. 탭마다 참가 세션이 다릅니다. 탭 복제로 같은 세션을 복사하기보다 새 탭에서 주소를 여세요.

방 만들기 → 6자리 코드 공유 → 방 참가 → 각자 준비 완료 → 방장 경기 시작 → 각자 지도에서 시작 지역 확정 → 전원 확정 후 전투 시작. 최대 4명이며 개발 검증용 2~3인 시작도 허용합니다. 봇 자동 충원과 공개 자동 매칭은 없습니다.

기본 주소는 이 컴퓨터에서만 접근 가능합니다. 별도 기기 연결은 같은 서버에 접근할 네트워크 구성이 필요하며, 기본 설정을 임의로 외부에 개방하지 않았습니다.

## 두 실행 환경의 차이

기존 Sites 주소는 정적 로비·선택·준비 설정·도감과 혼자 UI 연습을 제공합니다. 이 배포에는 Node 서버가 실행되지 않으므로 실제 비공개 방 대전은 로컬 실행에서만 가능합니다. 온라인 대전 서버 호스팅은 아직 연결하지 않았습니다. 실제 참가자처럼 보이는 가짜 매칭이나 봇은 넣지 않았습니다.

혼자 연습과 방 대전은 같은 game-core.js 규칙을 사용합니다. 둘 다 빵2/물3과 시작 장비만 지급합니다. 혼자 연습에는 실제 참가자가 없으며, 자동으로 가짜 서번트를 만들지 않습니다. 상황 테스트 메뉴로 서번트·시체 예시를 직접 생성할 수 있고 연습임을 표시합니다.

## 검증과 남은 범위

node --test game-server.test.mjs 로 방 권한·정원·준비, 상대 정보 비공개, 제작 예약/취소/완료, 이동 제한, 지역 보구/저항, 과부하 무승부, 기권 승리를 검사합니다. 브라우저 두 개에서 방 생성·서로 다른 서번트 참가·준비·시작·이동·탐색·기권·상대 우승을 확인했습니다.

확정된 첫 버전의 탐색·숙련도·성장·시체·전투·금지구역·령주·결과 규칙은 공통 엔진에 연결했습니다. 아래의 과거 버전 설명은 변경 이력입니다. 현재 구현 현황과 보류 범위는 reference/implementation-status.md를 보세요. 서버 방은 메모리에 보관하므로 서버 재시작 시 초기화되며, 실제 대전의 외부 호스팅·영구 전적·공개 운영 설비는 제공하지 않습니다.

## 파일

- dist/lobby.js, dist/lobby.css: 로비/준비/대기실/결과와 서버 연결.

공통 규칙 TXT는 사용자 요청에 따라 기존 파일 안에서 v0.4로 개정했습니다.

## v0.6 지도·빠른 버리기·시각 개선 (2026-11-03)

선택 지역 외곽선을 모든 지역 위에 별도 경로로 그려 인접 지역에 가려지지 않게 수정했습니다. 현재 위치 테두리도 위에 표시하며 선택 표시가 최상단입니다.
가방 아이템 위에 커서를 두고 V를 누르면 1개를 버립니다. 매 키 입력 때 현재 커서 아래 요소를 다시 확인하므로 서버가 가방 DOM을 갱신해도 이전 슬롯 요소를 재사용하지 않습니다. 키를 길게 눌러 반복해서 버리기, 입력창 입력 중, 로비·탈락·결과·모달 중의 새 호버 단축키는 차단합니다. 기존 아이템 상세창의 V 버리기는 유지합니다. 바닥 아이템 M에서 회수할 수 있습니다.
8개 지역별 자체 SVG 배경을 추가했습니다: 주택가 거리·학교 건물·공장 설비·성당·숲길·연못과 정자·항구 크레인·호텔. 캐릭터 이미지는 추가하지 않았습니다. 배경은 지역 이동 때 함께 바뀝니다.
검정/금색 중심 테마를 밝은 청회색 패널로 바꾸고, 탐색 녹색·이동 파랑·휴식 청록·공격 주황·보구 보라·령주 붉은색으로 구분했습니다. 지도 선택의 금색 표시는 버튼 색과 별개로 유지합니다. 글자 대비와 행동/아이템 안내 크기를 높였습니다.
브라우저에서 공장 전체 선택 테두리, 공장·연못 배경, 커서 아래 V키로 빵 2개→1개, M 창에 빵1개가 남는 동작을 확인했습니다.

## v0.7 원작22개 지역과 배치 (2026-11-03)

무작위 배치는 시작 시 물15/화살6/총알6/반창고10묶음,180초에 생명의 나무5/운석6/미스릴6/오우거 가죽2개입니다. 현재 열린 일반 지역에 배치하며 한번만 실행합니다. 도감에는 고정 지역과 무작위 시간을 구분하고 실제 무작위 위치/재고는 전송하지 않습니다. 원작 서버 원본이 아닌 공개 표 기준이며 충돌은 설계서 정리/원작 데이터/지역_22개_아이템_배치.json에 기록했습니다.

## v0.7.1 섬 지도 시각화 수정 (2026-11-03)

원작 루미아 지도(https://gamerch.com/blacksurvival/460820 및 해당 지도 이미지)를 직접 확인해 지역의 상대적 위치를 다시 배치했습니다. 항구/공장/슬럼은 북서쪽, 호텔/성당은 동쪽, 연구소는 중앙, 병원/숲은 남서쪽, 모래사장은 남쪽, 절/등대는 남동쪽입니다. 지형과 건물은 직접 작성한 SVG이며 원작 이미지 파일을 배포하지 않습니다.

균등 분할을 없애고 굴곡 있는 해안·도로·숲·산·물과22개 랜드마크로 표현합니다. 지역 경계는 수동으로 지정했고 선택/현재/폐쇄 상태만 강조합니다. 이름 표지판과 건물도 클릭할 수 있으며, 현재 위치/선택 경계는 건물 뒤에서 표시해 건물 그림을 가르지 않습니다. 기본 아이콘용 SVG 선 스타일이 지도 전체에 적용되지 않게 분리했습니다.

22지역, 아이템 배치/수량, 정원, 이동/폐쇄 규칙은 v0.7을 유지합니다. 지도 클릭 영역끼리 겹치지 않는지, 표지판 중심이 해당 구역에 들어가는지 검사합니다. 브라우저에서21개 일반 지역 표지판의 선택 결과/테두리, 건물 클릭, 키보드 선택을 확인했습니다.
