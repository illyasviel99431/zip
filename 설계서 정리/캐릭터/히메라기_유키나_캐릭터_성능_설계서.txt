2. 패시브 — 영시
경기 시작 시 준비된1회. 적 서번트의 다음 명중할 BASIC 공격1회 전체를 확정 회피.
실제 회피 후30초 뒤 재충전. 보유 최대1회, 시간 경과로 여러 회 충전하지 않음.
무기 종류와 무관. 전투 종료·이동·상대 교체로 쿨타임 초기화하지 않음.
빗나갈 공격·이미 전체 무효인 공격·동물·보구·함정·환경·탈진에는 미발동·미소모.
보구에 일반 공격 구성까지 포함돼 있어도 NOBLE_PHANTASM이면 영시 대상이 아님.
같은 BASIC 공격의 피해·적중 시 부가 효과를 차단. 한 공격의 다단 피해는1회로 회피.
공격 시도에 소모하는 상대 비용·CD·숙련도는 공통 규칙대로 처리.
첫 버전에는 가드가 없으며 영시만 별도의 회피다.

3. 보구 — 설하랑
NOBLE_PHANTASM, 현재 발견하여 공격 가능한 같은 지역의 적 서번트1명.
찌르기를 포함한 무기 장착 필요. 시전0초·STA10·CD55초(승인 시부터).
일반 공격100%+12+2×레벨 추가 피해. 두 직접 피해 구성은PHYSICAL.
일반 부분은DEF 적용, 추가 부분은DEF 우회. 명중 굴림 생략·치명타 없음.
무기 적중 옵션은1회, 숙련도도1회. 일반 공격을 대체하고1.5초 공격 간격을 공유.
동물에게 사용 불가. 사전 범위 경고 없음, 사후 피해·상태 로그만 제공.
추가 피해: Lv1=14 / Lv5=22 / Lv10=32 / Lv14=40 / Lv18=48.
다른 감소가 없고 일반 피해가40인 Lv18 예라면40+48=88.

4. 마력 간섭
보구가 유효 적중하고 대상이 생존하면10초 MAGIC 상태이상 부여 시도.
기본100%에 상태이상 저항 적용. 알트리아에게는 대마력으로80%.
그동안 상대가 새로 사용하는 다음 보구1회의 스킬 추가 피해 중,
간섭 시전자 유키나가 받는 부분만50% 감소. 보구 속성에는 제한 없음.
일반 피해·회복·강화·이동·다른 플레이어에게 주는 피해에는 영향 없음.
상대의 스킬 사용 자체를 막거나 이미 시작한 시전을 중단하지 않음.

상대 보구 사용 승인 시 간섭을 소비하고 해당 발동1회에 감소를 저장.
9초째 사용→11초째 적중도 감소. 부여 전에 이미 시작한 보구는 미적용.
연타·지속 피해는 동일 보구 발동에 속하는 추가 피해 전체에 적용.
빗나감·시전 취소·다른 적 대상·추가 피해 없는 보구여도 사용하면 소비.
10초간 새 보구를 사용하지 않으면 그대로 만료.
재부여는 남은 시간을10초로 갱신하고 횟수·감소율을 중첩하지 않음.
여러 유키나의 간섭은 각자 본인이 받는 부분만 감소. 한 피해에50%를 중복 적용하지 않음.
같은 시각 새로 시작한 보구에는 그 뒤 붙은 간섭을 소급하지 않음.
다른 피해 감소와 곱하고 총 비율 감소 상한60% 및 마지막 내림을 공통 적용.

5. 알트리아와의 상성
간섭 성공 뒤 알트리아가 Lv18 엑스칼리버를 새로 사용하면 유키나는92→46.
유키나의 마술 방어 장비10%도 있으면92×0.5×0.9=41.4→41.
그 지역 다른 대상은 각자의 저항으로 계산하며 이 유키나 간섭을 공유하지 않음.
알트리아가 시전을 먼저 시작했거나10초를 기다렸다면 간섭 없이92.
영시는 엑스칼리버를 회피하지 않음. 간섭 부여 자체는 대마력으로 실패할 수 있음.
설하랑의 직접 피해는PHYSICAL이라 대마력에 줄지 않지만,
장비로 발동한 MAGIC 추가 피해는 별도로25% 감소.

6. 운영·검증
일반 공격을 흘리며 탐색·제작할 기회를 확보하고 상대 보구가 필요할 시점을 예상해 먼저 견제.
공통 생존 령주3획·회복15%·철수·공통30초. 보구 강화에 사용 불가.
회복은HP 음식과5초CD 공유. 보구 시전 중 사용 제한은 공통 규칙.
낮은HP를 미리 상향하지 않고 영시가 막은 피해·간섭이 실제 줄인 피해·직접 화력을 각각 기록.
짧은 교전 후30초마다 재교전하는 운영이 과도한지, 4인 광역 상황과1대1을 별도로 검증.
상대가10초를 버티거나 다른 대상에게 보구를 써서 간섭을 소모시키는 대응도 허용.
즉시 적용되는 확정 방어가 아니라 보구를 먼저 걸어 두어야 하는 예측형 방어다.
