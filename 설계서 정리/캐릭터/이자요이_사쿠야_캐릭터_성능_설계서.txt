성배전쟁 웹게임 — 이자요이 사쿠야 성능 설계서
==============================================
문서 버전: v0.1 / 2026-11-06
상태: 신규 캐릭터 설계 제안, 게임 미구현·대전 검증 전.
출전: 동방Project / 클래스: Assassin / 주력: 투척D+(21점), 나머지F(0점).
채택한 모습: 시간 조작과 나이프를 활용하는 메이드. 실제 서버·다른 모든 플레이어의 시간을 멈추지 않음.
기준: 성배전쟁_공통_게임_규칙_v0.2.txt 내부v0.8 및 서번트_캐릭터_10종_관리표.txt 내부v0.6.
현재 게임의 실제 선택 가능 캐릭터는 알트리아·유키나2종. 이 문서 생성은 플레이 가능 추가가 아니다.
원작의 인물 특징을 자체 규칙으로 번역한 초안이며, 수치·효과가 원작 공식 능력이라고 주장하지 않는다.

1. 캐릭터의 목표와 차별점
시간 조작을 일상 작업의 빠른 처리와 한 대상의 짧은 제어로 축약. 키르아의 지속 가속과 달리 짧은 정지 구간에 나이프를 예약한다.

3. 패시브 — 완벽하고 소쇄한 메이드
본인의 일반 제작 시간1초→0.8초, 일반 장비 교체/무기 계열 변경0.5초→0.4초.
항상 적용, 비용0, CD없음. 작업 시간을 효율적으로 쓰는 성격과 시간 조작을 제작 운영으로 해석한다.
탐색·휴식 틱·공격·이동·시체 회수·재장전·보구 시전·금지 타이머·상태 지속시간은 바꾸지 않음.
성공/취소·재료 예약·가방 공간·기절로 인한 중단은 원래 제작/교체 규칙 그대로.
산출 수량·XP·숙련도를 늘리지 않고 이미 시작한 작업의 남은 시간을 재계산하지 않음.
장비를 빠르게 바꿔도 공격·보구·이동 CD는 초기화되지 않는다.

4. 보구(고유 액티브) — 시간 정지 — 나이프 매장 [프로젝트 재해석명]
유형: NOBLE_PHANTASM / 지연 지정 공격 / 발견한 적 서번트 1명.
투척 계열 무기와 장착 수량3개 이상 필요. 시전0초 / STA20 / CD70초.
승인 시 투척 무기3개 예약·소비하고 대상에게 MAGIC 기절0.75초 부여 시도.
기절 기본100%, 대마력·제어 면역·연속 제어3초 상한 적용. 실패해도 뒤의 나이프 예약은 유지.
승인0.75초 후 양쪽 생존·같은 발동 지역인지 재검증하여 PHYSICAL 추가 피해22+2×L을 한 번 적용.
피해 Lv1=24 / Lv9=40 / Lv18=58. 세 나이프 연출은 세 번의 적중/숙련도 판정이 아님.
일반 피해 없음, 명중 굴림·치명타 없음. 무기 옵션·숙련도 없음, 영시 대상 아님.
공격 간격은 승인 때 검사하고 일반 공격1회 간격을 예약하여 같은 순간 BASIC을 추가로 끼우지 못함.
본인은 예약된0.75초 동안 나이프 회수 대기: 이동·다른 주 행동·음식·령주 불가, 자발 취소 가능.
취소·기절·침묵·시전자 사망이면 예약 피해 취소, 이미 건 기절은 남은 시간대로 만료.
대상이 이동하거나 사망하면 불발. 대상의 침묵/기절 면역은 직접 피해 면역이 아님.
제어는 피해 지연을 포함해 실제 서버 시간을 정지시키지 않으며 지역·폐쇄·다른 사람 공격은 계속 진행.
같은 시각 피해·이동 요청 충돌은 공통 서버 사건 처리 순서를 따르며 클라이언트 시각으로 소급하지 않음.
모든 취소·불발에 STA/CD/무기3개 반환 없음. 간섭은 지연 추가 피해에 저장 적용.
지연 피해 전에 적용된 기절은 대상 HUD에 보이지만 사전 시전바를 별도로 공개하지 않는다.

5. 공통 판정·기존 두 캐릭터와의 연결
L은 사용 시 현재 레벨1~18. 원작 캐릭터의 공식 수치가 아닌 프로젝트 초기 제안값이다.
전투 자원HP/STA, 패시브1개+보구(고유 액티브)1개, 공통 생존 령주3획. 별도MP·가드 버튼·추가 액티브 없음.
아래 지정 보구는 모두 서번트 대상이며 동물 대상 사용은 명시된 강화 BASIC/패시브 외에는 불가.
일반 피해에는 DEF, 추가 피해에는 일반DEF 미적용. 속성 저항·간섭·약화·취약·보호막은 해당 구성에 적용.
피해는 한 공격의 구성들을 합산한 뒤 공통 순서에 따라 내림. DoT는 공통 틱당 판정을 따른다.
STA 보구 비용 부족 시 HP로 대납 불가. 승인 실패에는 소비 없음, 승인된 시전 취소에는 비용/CD 반환 없음.
별도 언급이 없는 영구 패시브는 침묵/버프 해제로 꺼지지 않음. 이미 완성된 강화 버프도 침묵만으로 삭제하지 않음.
기절은 새 행동을 막고 진행 중 주 행동을 취소, 침묵은 새 보구/진행 중 시전을 막는다. 이동불가는 일반/령주 이동을 막는다.
새 이동·시전·공격은 공통 주 행동 규칙을 따르며 공격/이동 대기를 초기화하지 않는다.
모든 새 보구의 CD는 사용 승인 시 시작. 공격 대체형은 기존 공격 간격을 공유하고 순수/강화 보구도 기존 대기를 초기화하지 않음.
목표가 있는 보구는 승인 당시 발견된 같은 지역 적이 필요. 광역/자기 강화는 대상 발견 불필요.
시전 바·적의 정확한CD·STA·가방·미공개 위치를 새로 노출하지 않는다.
가속·기절·출혈·취약 등은 공통 상태 정의/중첩/면역을 사용. 자기 대가는 명시적으로 저항 불가 예외로 구분.
일시 효과는 요청한 자기 상태HUD 위치에 아이콘·남은 시간·중첩·설명을 표시. 영구 패시브는 상시 효과 목록으로 설명한다.
개인 준비/중첩 카운터는 본인에게만 표시. 상대는 공통 공개 규칙에서 허용된 기절·출혈·취약 등만 확인한다.
광역과 지연 피해의 환경 우선·동시 피해·승패는 기존 공통 규칙을 변경하지 않는다.
확정 명중 보구도 명시적 공격 전체 무효가 있으면 공통 예외 우선. 유키나 영시는 BASIC만 회피한다.
강화 BASIC은 끝까지 BASIC이며 영시 적용. 보구가 붙인 추가 피해/DoT만 발동ID를 보존해 승인 시 저장한 간섭을 적용한다.
추가 피해 없는 보구도 간섭을 소비하나 회복·가속·일반 피해 증폭·제어 시간까지 반감하지 않는다.
여러 캐릭터의 유사 버프가 있다고 가속·취약·제어를 별도 칸에 중복 생성하지 않는다.
총/투척/둔기/권법은 현재 코드에서 전투 보류. 아래 시작 장비/수치는 관리표의 확장 초안을 구현한 이후의 제안이다.

6. 운영과 상대의 대응
상대가 제어 면역이면 기절이 실패해 이동으로 나이프를 피할 수 있다. 무기 수량3개와 보구 기회를 쓰므로 탄약·동선 관리가 필요하다.

7. 구현 전 필요한 작업
투척 수량·장착 묶음·상위 제작 경로, 작업 시간 수정자·지연 보구 취소 연결이 필요. 기절·HUD 기반은 기존 모듈 활용.
신규 기능은 서버와 혼자 연습의 공통 엔진에 함께 연결해야 한다. 현재 구현되었다는 뜻이 아니다.
현재212아이템·53제작법·지역 재고는 이 문서만으로 변경하지 않는다.

8. 검증할 항목
0.8/0.4초 작업만 변경; 취소 재료 복제 없음; 나이프3개 승인 소비; 기절 실패 후 이동;0.75초 동시 처리; 시전자 사망 후 피해 없음; 전역 시간 변화 없음.
4인 개인전에서 동일 캐릭터 중복, 서로 다른2종/14종 조합, 금지구역·11분 과부하까지 확인한다.
문서 산술 검산과 실제 대전 밸런스 검증은 구분한다. 검증 전 승률/동등한 성능을 보장하지 않는다.
