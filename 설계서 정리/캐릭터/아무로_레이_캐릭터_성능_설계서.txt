성배전쟁 웹게임 — 아무로 레이 성능 설계서
==============================================
문서 버전: v0.2 / 2026-11-06
상태: 게임v0.13.0 서버·혼자 연습 구현. 실제 다인 대전 밸런스 검증 전.
출전: 기동전사 건담 / 클래스: Rider / 주력: 총D+(21점), 나머지F(0점).
채택한 모습: 역습의 샤아 시기 ν건담·뉴타입·핀 판넬 기준. 기체 크기는 서번트 연출로 축약하며 별도 기체HP·탑승 조작 화면 없음.
기준: 성배전쟁_공통_게임_규칙_v0.2.txt 내부v0.9 및 서번트_캐릭터_10종_관리표.txt 내부v0.7.
현재 선택 가능: 알트리아·유키나·아무로·링크4종. 캐릭터 이미지는 미사용.
원작의 인물 특징을 자체 규칙으로 번역한 초안이며, 수치·효과가 원작 공식 능력이라고 주장하지 않는다.

1. 캐릭터의 목표와 차별점
감응으로 한 번의 피해를 줄이고 제한된 판넬을 실제 사격에 맞추는 병기 운용형. 시논의 준비된 한 발과 달리 일정 시간 같은 지역에서 여러 발을 맞혀야 한다.

3. 패시브 — 뉴타입 감응
적 서번트의 다음 명중할 BASIC 1회 전투 피해를 20% 감소. 준비 상태로 시작, 실제 발동 후12초 CD.
각 공격의 모든 피해 구성에 적용하며 다른 비율 감소와 곱하고 공통 감소 상한60%를 따른다.
공격의 적중 자체는 취소하지 않으므로 상태이상·상대 적중 카운터는 정상 판정한다.
빗나감·전체 회피·동물·NOBLE_PHANTASM·DoT·환경에는 미발동·미소모.
같은 시각 여러 BASIC을 받으면 공통 사건ID 순서의 첫 유효 공격 하나에만 적용한다.
지역 이동·타깃 변경·기체 연출 변경으로 재충전하지 않음. 최대1회, 비용0.
적 위치·가방·정확한 STA·보구CD를 알아내는 기능은 없다.

4. 보구(고유 액티브) — 핀 판넬
유형: NOBLE_PHANTASM / 자기 강화형. 총 무기 필요, 대상 발견 없이 사용 가능.
시전1초 / STA18 / CD70초 / 완료부터8초 동안 판넬3회.
판넬이 남아 있는 동안 총 BASIC을 승인하면 1회를 예약·소비한다.
그 BASIC이 적 서번트에게 명중하면 MAGIC 추가 피해 5+0.7×L. 빗나감·영시에는 피해 없음, 횟수는 반환하지 않음.
동물 BASIC에도 횟수와 탄약은 소비하지만 판넬 추가 피해는 주지 않는다.
추가 피해 1회 Lv1=5.7 / Lv9=11.3 / Lv18=17.6. 최대3회, 매 공격 공통 합산 내림 적용.
BASIC 본체의 명중·치명타·공격 간격·총알1발 소비는 그대로. 추가 피해는 치명타 불가.
직접 보구 공격이 아니라 강화된 BASIC이므로 영시로 본체와 판넬 모두 회피 가능.
유키나 간섭은 활성 승인 시 소비·대상 목록 저장. 해당 유키나에게 붙는 판넬 추가 피해만50% 감소.
강화 중 이동·총 해제·다른 계열 선택·사망이면 남은 횟수 소멸. 침묵은 활성화 시전을 막지만 완료된 판넬은 지우지 않음.
판넬은 독립 NPC가 아니며 자동 타깃·이웃 지역 공격·추가 숙련도·추가 적중 옵션이 없다.
일반 공격 대기·이동 대기를 초기화하지 않으며, 버프 활성 자체에는 총알이 들지 않는다.

5. 공통 판정·기존 두 캐릭터와의 연결
L은 사용 시 현재 레벨1~18. 원작 캐릭터의 공식 수치가 아닌 프로젝트 초기 제안값이다.
전투 자원HP/STA, 패시브1개+보구(고유 액티브)1개, 공통 생존 령주3획. 별도MP·가드 버튼·추가 액티브 없음.
아래 지정 보구는 모두 서번트 대상이며 동물 대상 사용은 명시된 강화 BASIC/패시브 외에는 불가.
일반 피해에는 DEF, 추가 피해에는 일반DEF 미적용. 속성 저항·간섭·약화·취약·보호막은 해당 구성에 적용.
피해는 한 공격의 구성들을 합산한 뒤 공통 순서에 따라 내림. DoT는 공통 틱당 판정을 따른다.
STA 보구 비용 부족 시 HP로 대납 불가. 승인 실패에는 소비 없음, 승인된 시전 취소에는 비용/CD 반환 없음.
별도 언급이 없는 영구 패시브는 침묵/버프 해제로 꺼지지 않음. 이미 완성된 강화 버프도 침묵만으로 삭제하지 않음.
기절은 새 행동을 막고 진행 중 주 행동을 취소, 침묵은 새 보구/진행 중 시전을 막는다. 이동불가는 일반/령주 이동을 막는다.
새 이동·시전·공격은 공통 주 행동 규칙을 따르며 공격/이동 대기를 초기화하지 않는다.
모든 새 보구의 CD는 사용 승인 시 시작. 공격 대체형은 기존 공격 간격을 공유하고 순수/강화 보구도 기존 대기를 초기화하지 않음.
목표가 있는 보구는 승인 당시 발견된 같은 지역 적이 필요. 광역/자기 강화는 대상 발견 불필요.
시전 바·적의 정확한CD·STA·가방·미공개 위치를 새로 노출하지 않는다.
가속·기절·출혈·취약 등은 공통 상태 정의/중첩/면역을 사용. 자기 대가는 명시적으로 저항 불가 예외로 구분.
일시 효과는 요청한 자기 상태HUD 위치에 아이콘·남은 시간·중첩·설명을 표시. 영구 패시브는 상시 효과 목록으로 설명한다.
개인 준비/중첩 카운터는 본인에게만 표시. 상대는 공통 공개 규칙에서 허용된 기절·출혈·취약 등만 확인한다.
광역과 지연 피해의 환경 우선·동시 피해·승패는 기존 공통 규칙을 변경하지 않는다.
확정 명중 보구도 명시적 공격 전체 무효가 있으면 공통 예외 우선. 유키나 영시는 BASIC만 회피한다.
강화 BASIC은 끝까지 BASIC이며 영시 적용. 보구가 붙인 추가 피해/DoT만 발동ID를 보존해 승인 시 저장한 간섭을 적용한다.
추가 피해 없는 보구도 간섭을 소비하나 회복·가속·일반 피해 증폭·제어 시간까지 반감하지 않는다.
여러 캐릭터의 유사 버프가 있다고 가속·취약·제어를 별도 칸에 중복 생성하지 않는다.
베기·찌르기·총 전투는 지원. 투척·둔기·권법은 아직 전투 보류다.

6. 운영과 상대의 대응
탄약과 발견 유지가 필요하다. 상대는 이동을 유도하거나 영시·은신·교전 단절로 8초를 소모시킬 수 있다. 무제한 자동 사격은 없다.

7. 구현 내역과 남은 검증
총 F~SS 숙련도·개체별 장전·1.5초 재장전·제작 경로·판넬 승인 시 간섭 저장을 공통 엔진에 구현. 거대 기체 별도 조작 화면은 없음.
서버·혼자 연습은 같은 게임 엔진을 사용한다. 신규 기능23개 자동 검증 및 기존72개 검증을 통과. 실제 참가자 다인 밸런스 검증은 남아 있다.
현재214아이템·57제작법. 원래212종과 고정 지역 배치는 보존하며 총 제작 경로4개와 고유 총2개를 확장했다.

8. 검증할 항목
동시 피격에서 감응 1회만; 판넬 승인 소비·영시·빗나감; 8초 만료; 간섭 저장의 대상 분리; 보구에 의해 강화된 BASIC의 공격 태그.
4인 개인전에서 동일 캐릭터 중복, 서로 다른2종/14종 조합, 금지구역·11분 과부하까지 확인한다.
문서 산술 검산과 실제 대전 밸런스 검증은 구분한다. 검증 전 승률/동등한 성능을 보장하지 않는다.
