이번 우선 명단은 직전 추천표의 클래스별2명을 사용자가 제작 요청한 것으로 정리했다.
후보14명과 동시 경기 인원4명은 다르다. 경기 인원 증가는 별도 결정이며 이 문서로 늘리지 않는다.
캐릭터 중복 선택 허용. 개발 검증2~3인 시작 가능. 신규 캐릭터는 공통 엔진과 대전 검증을 거쳐 추가한다.

한눈에 보는 패시브 / 보구:
Saber: 알트리아 — 대마력A / 엑스칼리버. 요우무 — 반령 동행 / 반령연참.
Lancer: 유키나 — 영시 / 설하랑. 돈키호테 — 편력 기사의 열정 / 정의를 향한 돌진.
Archer: 시논 — 저격수의 집중 / 정밀 저격. 레이무 — 부유하는 무녀 / 몽상봉인.
Rider: 아무로 — 뉴타입 감응 / 핀 판넬. 링크 — 스크래빌드 / 퇴마의 검격.
Caster: 프리렌 — 마법 수집가 / 졸트라크. 메구밍 — 폭렬도 / 익스플로전.
Assassin: 키르아 — 암살자의 보법 / 신속. 사쿠야 — 완벽하고 소쇄한 메이드 / 시간 정지·나이프 매장.
Berserker: 가츠 — 검은 검사 / 광전사의 갑주. 덴지 — 혈액 섭취 / 체인소 맨.

모습의 기준:
- 시논=GGO, 아무로=역습의 샤아·ν건담, 링크=왕국의 눈물, 돈키호테=기본LCB.
- 메구밍=폭렬마법, 덴지=덴지의 체인소 변신, 가츠=검은 검사와 광전사의 갑주.
- 여러 시대·다른 인격·최종 형태의 모든 능력을 한 캐릭터에 섞지 않는다. 사용자 변경 요청 시 기존 파일에서 개정한다.

이번에 설계하지 않은 세 번째 후보:
차해인 / 츠쿠모 유키 / 소닉 / 고죠 / 카즈마 / 카게야마 시게오(모브).
이들은 후보로만 보존하며 설계서·선택 가능한 캐릭터를 추가하지 않는다. 나머지 제안 후보 역시 이번 범위 밖이다.

공통 요건:
- 패시브1+보구1, HP/STA, 생존 령주3획, 별도MP/일반 액티브 없음.
- 일반 피해와 스킬 추가 피해, 공격 종류와 속성을 각각 구분.
- 스탯·성장·장착 조건·시전/비용/CD·명중·부가 효과·예외·출처·변경 이력 기록.
- 신규 수치는 초기 제안값. 18레벨 표를 산술 검산해도 대전 밸런스 검증을 대신하지 못한다.
- 기존 TXT를 직접 수정하고 내부 버전·이력을 갱신. 버전별 별도 TXT 생성 금지.

신규 명단의 확장 기록 — 1~9는 v0.6 당시 초안이며 아래 v0.7 현황을 우선:
1. 베기·찌르기 외 둔기/총/활/투척/권법을 구현할 경우 기존 F~SS 표를 공통 기준으로 사용한다.
   각 캐릭터 주력D+(21), 나머지F(0). 클래스는 역할 구분이며 원거리 사거리 보너스를 자동 부여하지 않음.
   Caster의 단봉 BASIC은 PHYSICAL 둔기 공격이다. 졸트라크·폭렬마법 등 보구만 명시한 MAGIC 판정을 사용한다.
2. 총 시작 제안: 일반 총1정, 무기6발 장전+가방 총알20발. 원작 자료상 해당 두 시작 총은6발 장전.
   BASIC/시논 정밀 저격은 승인 때 장전탄1발 소비. 빗나감·영시·승인 후 취소에도 반환하지 않음.
   재장전 제안1.5초, 주 행동1개. 완료 때 가방 총알을 빈 장전 칸만큼 옮기고 예약 해제. 취소 시 이전 탄약 보존.
   재장전 중 공격/보구 불가. 예약 총알은 제작/버리기 등과 중복 소비 불가. 무기 교체·사망·기절 시 취소.
   장전 수량은 아이템 개체에 귀속. 장착 해제·버리기·재장착으로 탄창을 무료로 채우지 않음.
   총마다 장전수·탄약종을 데이터로 명시해야 하며 자료 없는 무기는 활성화하지 않음. 원작 재장전 시간 완전 복제라는 뜻 아님.
3. 투척 시작 제안: 장착 묶음15개(투척용 단검). BASIC 승인 때 수량1개 소비, 사쿠야 보구는3개 소비.
   순수 MAGIC 보구와 자기 강화 활성화에는 탄약/투척물 소비 없음. 강화 후 실제 BASIC은 정상 소비.
   마지막 투척물도 승인 시 무기 성능을 저장해 정상 처리한 뒤 장착 수량0을 해제한다. 가방 수량과 중복 차감하지 않음.
   투척 수량은 실제 아이템 묶음으로 취급하고 전리품·제작·교환에서 수량 보존. 무한 재생 탄약 없음.
4. 새 무기 계열을 열기 전에 각 인물의 상위 무기 제작 경로·산출 수량·지역 수급을 점검·설계해야 한다.
   현재53제작법만으로 모든 계열의 완성 경로가 준비되었다고 주장하지 않는다. 이번에는212아이템/53제작법을 변경하지 않음.
5. 보구로 BASIC을 강화하는 아무로/덴지는 발동ID와 승인 시 간섭 대상목록을 저장한다.
   공격은 BASIC이므로 영시로 전체 회피 가능. 보구에서 온 추가 피해/출혈만 개인별 간섭50% 적용.
   일반 피해와 일반 무기 옵션은 해당 보구가 새로 생성한 추가 피해로 취급하지 않음.
6. 가츠/키르아처럼 추가 피해 없는 강화 보구는 기존 간섭을 소비하지만 일반 피해 배율·가속·제어 시간은 반감하지 않는다.
   이는 기존 유키나의 '스킬 추가 피해만 감소' 규칙을 유지한 결과다. 향후 변경은 두 설계서와 공통 규칙에서 함께 개정한다.
7. 링크 제작품은 개체ID·제작자ID, 총 장전량/투척 수량도 개체별 관리가 필요. 클라이언트 표시만으로 판정하지 않는다.
8. 새로운 개인 카운터는 본인에게만, 일시 상태는 기존 요청 위치에 아이콘·시간·중첩·설명으로 표시한다.
   출혈/화상3중첩·제어연속3초·면역2초·가속상한 등은 유지한다. 새 상태를 등록할 때 공통 상태표부터 확장한다.
9. 실제 출시는 각 계열 지원·공통 서버/연습 엔진·HUD·검증이 끝난 뒤 결정. 설계14명과 현재 구현2명을 UI에서 혼동시키지 않는다.
