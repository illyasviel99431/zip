# 성배전쟁 웹게임 — 온라인 알파 v0.14.0

블랙서바이벌의 지역 탐색·제작·생존 전투를 참고한 웹게임과 설계 자료입니다.

[온라인 플레이](https://grail-war-interface-1101.spriggan1019.chatgpt.site/)

방 만들기 → 초대 링크 또는 6자리 코드 공유 → 참가 → 각자 준비 완료 → 방장 시작 → 각자 시작 지역 확정 순서로 진행합니다. 최대 4명이며, 2~3인 시작도 지원합니다. 알트리아·유키나·아무로·링크를 선택할 수 있습니다. 캐릭터 이미지는 게임에 적용하지 않았습니다.

## 프로젝트 구성

- `grail-ui/online/`: 현재 온라인 버전. Worker·D1 서버, 게임 UI·공통 엔진, 이미지와 아이템 데이터, 마이그레이션과 테스트.
- `grail-ui/dist/`, `grail-ui/serve.mjs`: 기존 로컬 버전 보존본.
- `설계서 정리/`: 공통 규칙, 캐릭터별 설계와 원작 조사 자료. 버전은 기존 TXT 내부에서 관리합니다.
- `캐릭터 이미지/`: 검토용 콘셉트 보관본. 게임 적용 자산이 아닙니다.
- `.research-tools/`: 조사·가공·검증 도구.

## 온라인 소스 실행

`grail-ui/online/README.md`를 참고하세요. 새 복제본에서는 `hosting.example.json`을 `.openai/hosting.json`으로 복사한 뒤 의존성 설치와 빌드를 진행합니다. 예제 설정에는 기존 사이트의 ID나 인증 정보가 없습니다. 실제 사이트 배포 시 본인의 사이트 설정을 별도로 사용합니다.

임시 조사 캐시·인증 정보·로컬 DB·사이트별 배포 설정은 포함하지 않습니다. `package-lock.json`, DB 마이그레이션, 외부 라이브러리의 라이선스 고지는 소스와 함께 보관합니다.

## 검증

v0.14.0은 112개 자동 검증을 통과했습니다. 실제 공개 서버에서 로그인 없는 4인 참가·준비·경기 시작·재접속도 확인했습니다. 영구 전적·공개 자동 매칭·봇·랭크와 대규모 부하 검증은 포함하지 않습니다.

원작 조사 자료에는 출처가 포함되어 있습니다. 외부 작품·위키·라이브러리의 권리는 각 권리자와 해당 이용 조건을 따릅니다. 이 저장소가 외부 자료에 대한 별도 사용 허가를 부여하지 않습니다.
