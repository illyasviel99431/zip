# zip
성배전쟁 웹게임 UI와 설계 자료입니다.

- `grail-ui/`: 브라우저에서 실행하는 UI 프로토타입
- `새 폴더/`: 게임 설계서와 블랙서바이벌 원작 조사 데이터
- `.research-tools/`: 데이터 조사·검증·가공 스크립트

`grail-ui/dist/index.html`을 열거나 `grail-ui`에서 `node serve.mjs`를 실행합니다. 실제 대전 서버는 연결되지 않은 UI 시제품이며, 캐릭터 그림은 빈 영역으로 준비되어 있습니다.

임시 조사 캐시와 사이트별 배포 설정은 포함하지 않습니다.
