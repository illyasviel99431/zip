## 출처 접근 등급

- **A**: 원 개발사 공식 공지의 본문을 직접 열어 확인. 해당 날짜/버전의 근거다.
- **B**: 커뮤니티 문서를 직접 열어 확인. 원작 최종 버전과 일치한다고 보증하지 않는다.
- **C**: 검색 도구가 반환한 색인 본문에서 관련 내용을 확인. 직접 페이지 접근은 제한되거나 실패했다. 전문 전체 열람을 뜻하지 않는다.
- **D**: 복원 프로젝트 문서. 원작과 변경 여부를 별도 검증해야 한다.
- **E**: 검색 결과의 제한된 부분에서 존재/일부 항목만 확인. 세부 규칙 근거로 쓰지 않는다.

페이지 제목에 ‘Official Wiki’가 있어도 사용자 편집 위키이며 개발사 공식 패치와 같은 등급이 아니다. 최근 크롤링 날짜도 수치의 적용 패치 날짜가 아니다.

## 원작을 웹게임으로 구현할 때 필요한 검증 목록

아래는 조사 결과로부터 도출한 구현 검증 제안이다. 원작 서버 내부 구조를 확인했다는 의미가 아니다.

- [ ] 기준 버전을 하나 지정하고 모드/빌드별 수치를 분리한다.
- [ ] 탐색 판정 순서, 없는 대상의 건너뛰기, 빈 탐색, 조우 보정을 확인한다.
- [ ] 지역 아이템 재고·버린 아이템·시체 전리품을 여러 명이 동시에 가져갈 때 중복 지급이 없는지 확인한다.
- [ ] 무기 계열/복합 숙련도/장전/투척 소진/무기 교체의 이벤트 순서를 확인한다.
- [ ] 무기 손상 단계·수리·불괴·보호 횟수·PRD와 캐릭터 예외를 확인한다.
- [ ] 일반 피해·스킬 피해·방어력·고정 감소·속성 저항을 분리하고 적용 순서를 정한다.
- [ ] 명중 실패·가드·치명타 때 추가 효과와 숙련도 획득 여부를 확인한다.
- [ ] HP/STA 회복의 타이머 공유, 숙취, 부상과 회복 증감 효과를 확인한다.
- [ ] 조건부 패시브가 HP 변경 직후 켜지고 꺼지는지 확인한다.
- [ ] 설치물·함정·지역 효과의 소유자 이동/탈락 후 생존 여부를 확인한다.
- [ ] 시전·중단·쿨타임 시작·소모/환불·사망/가사·동시 사망의 순서를 정한다.
- [ ] 금지구역 확정 시점의 탐색/이동/회복/시전과 탈락 판정 순서를 정한다.
- [ ] 낮/밤 변경, 출현/재출현, 보급 요청 창을 경기 경과 시간에 맞춘다.
- [ ] 상대 정보의 최초 공개·갱신·만료·추적·총성 범위를 확인한다.
- [ ] 해킹 시도 성공과 최종 승리 단계를 별도로 처리한다.
- [ ] 원작 수치가 없는 네트워크/재접속 정책은 자체 설계라고 명시한다.

## 추가 조사의 실제 제한

- 직접 열기에 실패한 Fandom 문서는 색인 본문을 이용했다. 공개 자료가 누락된 지점은 남겨 두었다.
- 공식 2018/2019/2021 기록은 열람했지만 2022년 서비스 마지막 빌드의 전체 패치 연쇄를 확보하지 못했다.
- Project Lumia 홈페이지/매그너스 문서는 열렸지만 문서 전체 색인과 일부 Markdown 주소는 열리지 않았다. 복원판을 원작 최종판으로 취급하지 않았다.
- 원작 실행, 비공개 서버 코드, 클라이언트 추출 데이터는 확인하지 않았다.
- 따라서 이번 결과는 넓은 시스템 조사와 충돌 대장이며, 전 아이템·전 캐릭터의 완전 검증 데이터베이스가 아니다.
