# 블랙서바이벌 원작 데이터 조사

현행 게임 설계는 [공통 규칙 내부 v0.3](../성배전쟁_공통_게임_규칙_v0.2.txt) 기준으로 초기 캐릭터 2종·기본 4인 개인전이다. 다른 캐릭터는 미정이며 10종 완성이 출시 조건은 아니다. 원작 수집 자료 662종과 실제 첫 버전에 채택한 102종을 구분한다. 실제 아이템·배치·변경 효과는 [게임 아이템 데이터](../게임_아이템_데이터.json)와 공통 규칙 부록에 있다. 아래의 10종 관리 언급은 조사 당시 맥락이다.

확인일: 2026-11-01. 이터널 리턴이 아닌 원작 블랙서바이벌 자료다. 연결된 공통 규칙 v0.2, 서번트 10종 관리표, 알트리아 v2.2를 읽고, 이 프로젝트의 캐릭터·보구 설계에 필요한 비교 자료로 수집했다. 사용자 원본 설계 TXT는 변경하지 않았다.

## 이번에 확보한 범위

- 원작 캐릭터 53명: 5성 ATK·DEF·HP·STA의 레벨 1/9/18과 성장값, 1~4성 레벨 1/18 표, 시작 숙련도.
- 일반 개인전 스킬 106개: 발동 조건, 수치·계수, 비용·지속시간·재사용 시간 및 예외를 한국어로 정리. 미기재 수치는 미기재로 남김.
- 아이템 662종: 일본어 위키 현재 목록 641종 및 삭제 목록 21종. 각각 개별 문서를 읽음. 영문 18개 분류의 644종·677행을 모두 연결.
- 아이템별 등급·기본 수치, 장탄/묶음 수량, 효과, 직접·하위 제작 트리, 재료별 획득 장소·배치 수량, 제작 XP·숙련도 중 각 문서에 제공된 표를 보존. 무조건 모든 항목에 모든 필드가 있는 것은 아님.

## 해석상 중요한 발견

목록만 읽으면 삭제된 조잡한 시작 무기 7종이 현재 장비처럼 섞인다. 일본어 보존 문서에서는 삭제 목록에 속한다. 반대로 영문 목록에 없던 음식 4종은 일본어 현재 목록에서 추가로 확인했다. 총의 예전 실총 이름과 변경된 가상 이름도 별도로 연결했다.

기본 능력치에서도 영문·일본어 간 10개 필드가 다르며, 일본어 5성 성장 표 자체의 불일치는 4개 셀이다. 아이템 숫자·등급 차이는 52종에서 확인했다. VF 특성은 2022-04-20 삭제 기록이 있어 과거 수치로 분리했다. 이 차이를 무시하고 하나의 밸런스 표로 섞지 않는다.

낮은 성급 끝점에서도 공개 공통 성장값과 다른 셀 14개를 따로 기록했다. 일본어 현재 분류표 641종과 개별 문서를 독립 대조한 결과, 바스타드 소드 ATK가 분류표 34/개별 문서 26으로 달랐다. 다른 출처와 숫자가 다르다는 사실은 패치 차이·기록 오류·수량 단위 차이 중 무엇 때문인지까지 확정한 것은 아니다.

스킬은 주 표뿐 아니라 표 아래의 발동·예외 설명도 확인해 한국어 추가 판정으로 정리했다. 예를 들어 비앙카의 무기 미사용/독립 CD 없음, 바바라 드론의 자기 피해, 라우라의 가방 칸 단위 합산, 니키·펠릭스의 가드 피해 감소 합산을 포함한다.

데이터 검사 결과: 53명·106스킬·662종 고유 항목, 현재 분류표 641종의 개별 문서 연결, 영문 목록 644종의 이름 연결, 직접 제작 재료 이름 연결을 확인했다. 필수 필드·연결 누락 검사를 통과했으며 출처 자체의 모순은 수정하지 않고 보존했다.

## 설계에 적용할 때

목표는 마스터가 서번트를 운용하는 실시간 지역 탐색·제작·생존 PvP를 만드는 것이다. 원작 캐릭터를 비교할 때는 기본 능력치+성장+숙련도+장비 제작 비용+회복 경제+패시브/능동 스킬의 실전 기회비용을 함께 본다. 네 설계의 HP/STA, 패시브 1개+보구 1개, 생존용 영주 3획, 보구 사전 지역 예고 없음이라는 조건에 맞춰 변환해야 한다. 관리표의 선택지 10종을 한 경기 인원 10명으로 해석하지 않는다.

이 조사에서 수집·대조를 완료한 것과 원작 최종 패치로 확정한 것은 다르다. 현재는 **모든 캐릭터 및 수집 목록 전체의 세부 자료를 확보한 상태**이며, 모든 값을 단일 최종 패치의 확정값이라고 주장할 수는 없다.
